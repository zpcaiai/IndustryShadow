# Incident handling

Assign commander, operations, security, domain, and communications roles. Record an
UTC timeline and scope; choose a safe degraded mode before recovery. Preserve evidence,
avoid secrets/raw sensitive values in chat or tickets, and link every action to an owner.
Exit only after integrity, tenant isolation, read-only boundaries, action recovery,
monitoring, and rollback readiness are verified. Publish learning actions and trigger
recertification for every changed build, policy, schema, Pack, model, or dependency.
